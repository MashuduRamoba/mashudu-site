How I Passed Azure AZ-900 in 3 Weeks While Working Full Time

The AZ-900 is labelled "entry level" but it still took real preparation. Here's my exact study plan, the free resources that actually helped, and what to focus on if you're writing the exam soon.

MR
Mashudu Ramoba
Microsoft Azure Fundamentals (AZ-900) · Certified 2024

When I decided to get the AZ-900, I was already working full time as an IT intern at Landis+Gyr. I had evenings and weekends — that's it. Three weeks later I walked out of the exam centre with a pass. Here's exactly how I did it.

What the AZ-900 Actually Covers

The exam has four main domains — and they're not equally weighted. Focus your time accordingly:

  • Describe cloud concepts (25–30%) — IaaS vs PaaS vs SaaS, shared responsibility model, high availability, scalability, elasticity, CapEx vs OpEx.
  • Describe Azure architecture and services (35–40%) — core services: Compute, Networking, Storage, Databases. Azure regions, availability zones, resource groups.
  • Describe Azure management and governance (30–35%) — Azure Cost Management, Azure Policy, RBAC, Microsoft Defender for Cloud, Azure Monitor.
⚠️ Don't Make This Mistake

Most people over-study cloud concepts (the easy section) and under-study management and governance (the hardest section). Flip that ratio. Governance and security questions will make or break your score.

My 3-Week Study Plan

Week 1 — Foundation

Goal: Understand cloud fundamentals and Azure's core architecture.
Daily: 1 hour on Microsoft Learn — work through the AZ-900 learning path from start to finish. Don't skip anything, even if it seems obvious.
End of week: Take a free practice test (MeasureUp or Whizlabs). Don't worry about your score — identify which domains you're weakest in.

Week 2 — Services Deep Dive

Goal: Learn every Azure service mentioned in the exam outline.
Daily: 1 hour on John Savill's AZ-900 YouTube series (free, excellent). One video per evening. Take notes in your own words — not copy-paste.
Focus areas: Azure Virtual Machines, Azure App Service, Azure Functions, Azure Storage types (Blob, File, Queue, Table), Azure SQL, Cosmos DB, Virtual Networks, VPN Gateway, ExpressRoute.

Week 3 — Governance & Practice Tests

Goal: Nail governance/security and do timed practice exams.
Daily: 30 min reviewing governance topics + 30 min practice questions.
Focus areas: Azure Policy, Blueprints, RBAC, resource locks, tags, Cost Management + Billing, Azure Advisor, Service Health, Monitor, Log Analytics.
Days 5–7: Do full timed practice exams (45 questions, 45 minutes). Aim for 80%+ before booking the real exam.

Free Resources That Actually Helped

📘
Microsoft Learn — AZ-900 Learning Path Free
The official material. Directly maps to exam objectives. Do all of it. learn.microsoft.com/en-us/certifications/azure-fundamentals/
▶️
John Savill's AZ-900 Study Cram (YouTube) Free
Single 3-hour video that covers the entire exam. Watch it in Week 2 after you have the foundation. Incredibly thorough.
🧪
MeasureUp Practice Tests Paid — Worth It
The closest simulation to the real exam. If you're scoring 80%+ here consistently, you're ready. About R400 for access.
📝
ExamTopics AZ-900 Questions Free
Community-sourced practice questions. Good for extra drilling but verify answers — some are outdated. Use as supplementary only.

On Exam Day

  • Read every question twice. Microsoft uses very precise language. "Which service would you use to..." vs "Which service is designed for..." have different answers.
  • Flag and return to any question you're unsure about. Don't spend more than 90 seconds on one question.
  • Eliminate wrong answers first. Usually two options are clearly wrong — narrow it to two then choose.
  • Trust your preparation. If you've done the Microsoft Learn path and practice tests, you know this material. Don't second-guess yourself.
✅ Pro Tip

Book your exam date before you finish studying. Having a real deadline forces you to study consistently. Without a booking date, "I'll do it when I'm ready" turns into never.

KEY TAKEAWAYS

  • 3 weeks is enough — 1 hour per day of focused study is all you need
  • Spend more time on governance/security than cloud concepts
  • Microsoft Learn + John Savill YouTube + MeasureUp practice tests = everything you need
  • Book your exam date before you feel "ready" — it forces accountability
  • Score 80%+ consistently on practice tests before writing the real exam

The AZ-900 is a great starting point for a cloud career — but don't stop there. My next target is the AZ-104 (Azure Administrator). If you're preparing for AZ-900 right now and want to compare notes, find me on LinkedIn.
