Python Automation for Beginners: From Script to Real-World Tool

I used Python to build monitoring scripts that reduced infrastructure downtime by 30% at Huawei. You don't need to be a Python expert to automate real things. Here's how to start — with code you can actually use.

MR
Mashudu Ramoba
Software Developer · LNOC Operator · Huawei/MTN · github.com/MashuduRamoba

During my time as a Generator Dispatch Operator at Huawei/MTN, I watched engineers spend hours every day on tasks that were essentially the same — checking the same systems, sending the same alerts, logging the same data. I knew Python could automate most of it. So I built the scripts. The result: a 30% reduction in infrastructure downtime because we were catching problems faster, automatically.

You don't need to be a Python expert to build automation tools that actually matter. This guide will take you from a blank file to a real, working script you can adapt for your own work.

What Makes Python Perfect for Automation

  • Readable syntax — Python reads almost like English. You can understand what a script does even if you didn't write it.
  • Huge standard library — file handling, networking, scheduling, sending emails — all built in, no installs needed.
  • Third-party packages — requests for HTTP, smtplib for email, schedule for cron-style jobs, pandas for data. Almost anything you need already exists.
  • Cross-platform — the same script runs on Windows, Linux, and macOS.

The 4 Most Useful Automation Patterns

Every automation script I've ever written falls into one of these four patterns. Learn these and you can build almost anything.

Pattern 1 — File Automation

Automatically move, rename, organise, or process files based on rules.

# Organise downloads folder by file type
import os
import shutil

FOLDER   = "C:/Users/YourName/Downloads"
TARGETS  = {
    "Images":    [".jpg", ".jpeg", ".png", ".gif", ".webp"],
    "Documents": [".pdf", ".docx", ".xlsx", ".txt", ".csv"],
    "Videos":    [".mp4", ".mov", ".avi", ".mkv"],
    "Code":      [".py", ".js", ".html", ".css", ".json"],
}

for filename in os.listdir(FOLDER):
    filepath = os.path.join(FOLDER, filename)
    if not os.path.isfile(filepath):
        continue
    ext = os.path.splitext(filename)[1].lower()
    for folder_name, extensions in TARGETS.items():
        if ext in extensions:
            dest = os.path.join(FOLDER, folder_name)
            os.makedirs(dest, exist_ok=True)
            shutil.move(filepath, os.path.join(dest, filename))
            print(f"Moved {filename} → {folder_name}/")
            break

print("Done! Downloads folder organised.")
✅ Try This Now

Copy this script, update the FOLDER path to your actual Downloads folder, and run it. Your files will be sorted into subfolders automatically. This is a real, useful script — not just a tutorial exercise.

Pattern 2 — Monitoring & Alerting

This is exactly what I built at Huawei — continuously check something and alert when it crosses a threshold. Here's a simplified version that monitors system resources:

import psutil
import time
import smtplib
from email.mime.text import MIMEText

ALERT_EMAIL    = "you@email.com"
CPU_THRESHOLD  = 85   # %
MEM_THRESHOLD  = 90   # %
CHECK_INTERVAL = 60   # seconds

def send_alert(subject, body):
    """Send an email alert."""
    msg = MIMEText(body)
    msg["Subject"] = f"[ALERT] {subject}"
    msg["From"]    = ALERT_EMAIL
    msg["To"]      = ALERT_EMAIL
    # Configure your SMTP server here
    # with smtplib.SMTP("smtp.gmail.com", 587) as server:
    #     server.starttls()
    #     server.login(user, password)
    #     server.send_message(msg)
    print(f"ALERT: {subject}\n{body}")  # print for now

def check_system():
    """Check CPU and memory usage."""
    cpu = psutil.cpu_percent(interval=1)
    mem = psutil.virtual_memory().percent

    if cpu > CPU_THRESHOLD:
        send_alert(
            f"High CPU Usage: {cpu:.1f}%",
            f"CPU usage has exceeded {CPU_THRESHOLD}%.\nCurrent: {cpu:.1f}%\nTime: {time.ctime()}"
        )

    if mem > MEM_THRESHOLD:
        send_alert(
            f"High Memory Usage: {mem:.1f}%",
            f"Memory usage has exceeded {MEM_THRESHOLD}%.\nCurrent: {mem:.1f}%\nTime: {time.ctime()}"
        )

    print(f"[{time.strftime('%H:%M:%S')}] CPU: {cpu:.1f}%  MEM: {mem:.1f}%  — OK")

print("Monitoring started. Press Ctrl+C to stop.")
while True:
    check_system()
    time.sleep(CHECK_INTERVAL)

Install the one dependency with: pip install psutil

Pattern 3 — Scheduled Reports

Run a task automatically at a specific time every day or week using the schedule library:

import schedule
import time
import csv
from datetime import datetime

def generate_daily_report():
    """Generate a CSV report of today's data."""
    timestamp = datetime.now().strftime("%Y-%m-%d")
    filename  = f"report_{timestamp}.csv"

    # Replace this with your actual data source
    data = [
        {"metric": "CPU Avg",   "value": "42%",   "status": "OK"},
        {"metric": "Memory Avg","value": "67%",   "status": "OK"},
        {"metric": "Uptime",    "value": "99.8%", "status": "OK"},
    ]

    with open(filename, "w", newline="") as f:
        writer = csv.DictWriter(f, fieldnames=["metric", "value", "status"])
        writer.writeheader()
        writer.writerows(data)

    print(f"[{timestamp}] Report generated: {filename}")

# Run at 08:00 every weekday
schedule.every().monday.at("08:00").do(generate_daily_report)
schedule.every().tuesday.at("08:00").do(generate_daily_report)
schedule.every().wednesday.at("08:00").do(generate_daily_report)
schedule.every().thursday.at("08:00").do(generate_daily_report)
schedule.every().friday.at("08:00").do(generate_daily_report)

print("Scheduler running. Reports will generate at 08:00 Mon–Fri.")
while True:
    schedule.run_pending()
    time.sleep(30)

Install with: pip install schedule

Pattern 4 — Data Processing

Read a CSV, process the data, output a summary. This is the foundation of almost every data automation task:

import csv
from collections import defaultdict

def analyse_stock_report(filename):
    """Read inventory CSV and identify low-stock items."""
    low_stock   = []
    total_value = 0
    category_totals = defaultdict(float)

    with open(filename, newline="") as f:
        reader = csv.DictReader(f)
        for row in reader:
            qty      = int(row["quantity"])
            reorder  = int(row["reorder_level"])
            price    = float(row["price"])
            category = row["category"]

            value = qty * price
            total_value += value
            category_totals[category] += value

            if qty <= reorder:
                low_stock.append({
                    "sku":      row["sku"],
                    "name":     row["name"],
                    "qty":      qty,
                    "reorder":  reorder,
                    "status":   "OUT OF STOCK" if qty == 0 else "LOW STOCK"
                })

    # Print summary
    print(f"\n{'='*50}")
    print(f"INVENTORY ANALYSIS REPORT")
    print(f"{'='*50}")
    print(f"Total Stock Value:  R{total_value:,.2f}")
    print(f"Low / Out of Stock: {len(low_stock)} items")
    print(f"\nBy Category:")
    for cat, val in sorted(category_totals.items(), key=lambda x: -x[1]):
        print(f"  {cat:<20} R{val:>10,.2f}")

    if low_stock:
        print(f"\n⚠ Items Needing Attention:")
        for item in low_stock:
            print(f"  [{item['status']}] {item['sku']} — {item['name']} ({item['qty']} left)")

    return low_stock

# Usage
low_items = analyse_stock_report("inventory_export.csv")

Turning a Script into a Real Tool

The difference between a script you run once and a tool you rely on every day comes down to three things:

  1. Error handling — wrap your main logic in try/except blocks. Log errors to a file instead of crashing silently.
  2. Configuration — put all settings (file paths, thresholds, email addresses) at the top of the file in clearly named constants. Better yet, use a config file.
  3. Logging — use Python's built-in logging module instead of print() statements. Your logs will have timestamps, severity levels, and can write to a file automatically.
import logging

# Set up logging once at the top of your script
logging.basicConfig(
    level    = logging.INFO,
    format   = "%(asctime)s [%(levelname)s] %(message)s",
    handlers = [
        logging.FileHandler("monitor.log"),  # write to file
        logging.StreamHandler()              # also print to console
    ]
)

# Then use it anywhere
logging.info("Monitoring started")
logging.warning(f"CPU at 87% — above threshold")
logging.error("Failed to connect to server")
⚠️ Before Running Any Script

Test on a copy of real data first. Never run an automation script that modifies or deletes files on live data until you've tested it thoroughly. Add a DRY_RUN = True flag that prints what the script would do without actually doing it.

KEY TAKEAWAYS

  • The 4 core automation patterns: File, Monitoring/Alerting, Scheduled Reports, Data Processing
  • psutil, schedule, requests, smtplib — four libraries that cover 80% of automation use cases
  • Always add error handling, configuration constants, and logging before calling a script "production-ready"
  • Start with your own most repetitive task — not a tutorial project
  • Use a DRY_RUN flag to test safely before touching live data

All the scripts above are starting points — take them, adapt them to your specific situation, and make them yours. The monitoring script in particular is very close to what I actually built at Huawei/MTN, just simplified for readability.
